Pon aquí las dos canciones. Da igual si son .mp3 o .m4a:
el reproductor prueba las dos y usa la que encuentre.

  admv                      → ADMV — Maluma
  perdonar-y-agradecer      → Perdonar y Agradecer — Sharif

Cualquiera de estos cuatro nombres sirve:

  audio/admv.m4a
  audio/admv.mp3
  audio/perdonar-y-agradecer.m4a
  audio/perdonar-y-agradecer.mp3

Con los archivos aquí, la música suena desde el teléfono: sin anuncios, sin
depender de YouTube y sin gastar datos. Las letras ya están cronometradas
contra el tiempo del audio, así que no se desfasan.

Si un archivo no está, esa canción cae sola al reproductor de YouTube (el de
siempre). Para forzar YouTube aunque los archivos existan, abre el sitio con
?source=yt al final de la dirección.

Después de dejarlos aquí, subir:

  cd ~/Trabajo/Clientes/carmen-3-meses
  git add audio && git commit -m "Songs" && git push
